```md
# DevSecOps App Sesi 30

## Deskripsi
Project FastAPI sederhana dengan implementasi DevSecOps pipeline menggunakan GitHub Actions.

## Features
- Unit Testing dengan Pytest
- SAST menggunakan Bandit
- SCA menggunakan pip-audit
- Secret Scanning menggunakan Gitleaks
- Docker Build & Push
- Image Scanning menggunakan Trivy

## Tech Stack
- FastAPI
- Docker
- GitHub Actions
- Docker Hub

## Pipeline
Workflow CI/CD:
- unit_test
- sast
- sca
- secret_scan
- build_and_push
- image_scan
```
